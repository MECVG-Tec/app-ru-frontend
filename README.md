# 🍽️ RU Fácil

**RU Fácil** é uma aplicação web desenvolvida em **Next.js 15** com **TailwindCSS** e **shadcn/ui**, criada para facilitar o acesso e gerenciamento das refeições do Restaurante Universitário (RU) da **UFRPE**.

O projeto foi desenvolvido como parte de uma atividade acadêmica, com foco em boas práticas de front-end, autenticação via contexto e rotas protegidas.

---

## 🚀 Tecnologias utilizadas

- [Next.js (App Router)](https://nextjs.org/)
- [React](https://react.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [TypeScript](https://www.typescriptlang.org/)
